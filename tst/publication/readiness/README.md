# PIC Readiness Registry

This directory stores compact, source-controlled control records for the MHD-PIC
production-readiness program. It does not contain simulation output and does not
qualify any scientific claim by itself.

## Files

- `storage_policy.json`: authorized Frontier root, budget cap, Project Home
  ledger mirror, user-selected Orion-only bulk-evidence design, and explicit
  terminal durability-risk disposition.
- `claims_registry.json`: stable claim IDs and their initial gate dependencies.
- `findings_registry.json`: initial implementation and operational findings.
- `external_artifacts.json`: provenance and redistribution inventory for paper,
  Entity, reference-data, and plotting artifacts.
- `entity_snapshot.json`: frozen accessible Entity comparison tree and

## Rules

1. Keep large artifacts outside Git under the authorized Frontier root.
2. Initialize and use the Frontier ledger only through the installed immutable
   control plane after Orion and the Project Home ledger mirror pass preflight.
3. Do not promote a claim to `qualified` while its reviewer is
   `pending external review`.
4. Run the readiness registry regression after editing these records:

```bash
python3 tst/publication/test_pic_readiness_registry.py
python3 tst/publication/test_pic_qualification_manifest.py
```
