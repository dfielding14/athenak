Task 2 scratch prototype audit (2026-10-06)
=========================================

Recommendation
--------------
The narrow optional implementation is feasible, and actual CPU PDE tests now
cover second-order temporal differences, successful merging, deterministic CFL
rejection/rollback, and MPI coordination. Retain it as a research candidate until
GPU acceptance and useful same-allocation timing are established. Do not advertise
the asymptotic stage reduction as a measured wall-clock improvement. In particular,
explicitly strict unit/paper wave inputs fall back to ordinary halves. The
original active turbulence deck instead has strict_admissibility=false by default;
it is still ineligible because its mirror/firehose limiter flags and finite
limiter rates are enabled. Neither case gains performance from this version.
Do not weaken scientific settings to manufacture eligibility.

Exact applicability
-------------------
sts_merge_half_sweeps is optional and defaults off. Reading the absent option does
not insert it into serialized inputs. The configuration gate requires CGL LF-only
RKL2, one parabolic process, a strictly periodic uniform mesh, no refinement,
no user source/boundary, no other diffusion/field-update process, and no additional
physics that changes the transaction state. Passive CGL is explicitly excluded
until J/A-to-U/mu conversion and rollback have separate acceptance. Physical and soft collision rates
must both be exactly zero; all configurable microinstability/backup limiters must
be disabled. Strict admissibility forces ordinary halves because existing fatal
checks cannot be rolled back. Forcing remains after an accepted pre operation.

The unconditional firehose wall still exists. The removed intermediate wall
checkpoint is not mathematically equivalent on wall-active nonsmooth states.
The candidate rejects a trial if a stage reports floor/nonfinite/nonpositive/
hard-bound events, but configuration alone does not prove the omitted checkpoint
would stay inactive. Current convergence evidence is explicitly smooth and clean.
No full nonlinear or wall-active convergence theorem is claimed.

Transaction and synchronization
-------------------------------
An eligible old post half is deferred only when no predicted output/final barrier
occurs. The next cycle combines its duration with the new pre half. The transaction
snapshots u0/w0 (including ghosts and possible repaired components), EOS counters,
LF cumulative diagnostics, slot representation and local timestep estimates. The
LF-only uniform periodic graph mutates no B state. It uses MPI_BOR to combine
rejection reasons and accepts only a fresh positive finite advective budget that
admits the trial cycle dt, with no new unacceptable state events.

On rejection the snapshot is restored, rejected temperature caches invalidated,
and u_sts1/u_sts_rhs cleared before ordinary stage1: even a zero RKL coefficient
does not safely suppress NaN/Inf in those old registers. Remaining stage registers
are initialized by stage1. Private LF sweep-work registers reset at stage1; private
hyperbolic pressure-work origins are unchanged by the LF attempt. Rejected profile
work remains counted separately; physical diagnostics are restored. The old post
then completes at its saved old time and duration, a fresh next dt is selected,
and the caller runs an ordinary new pre half.

Output prediction mirrors the actual float32 time and dcycle predicates. Explicit
backstops flush before outputs, AMR, finalization and an unpredicted wall stop.
The late-wall path also recomputes the next dt from the completed state, preserving
the old cycle's factor-two growth cap. Restart format gains no deferred state.
Nonzero rates always take the untouched ordinary path and are never moved across
a noncommuting diffusion operator. sts_max_dt_ratio retains its original policy;
the new fresh safeguard is an advective limit, not another parabolic-ratio policy.

Cost
----
For six CGL variables in double precision and no passive scalars, snapshots cost
96 bytes per stored cell including ghosts. An accepted attempt copies192 bytes
per cell. A rejected attempt adds192 bytes of restore traffic plus96 bytes for
the two register clears. Two global/device fences and an MPI accept reduction
are added per attempt. Snapshot allocation occurs only on the first attempt.
Successful operation replaces two half sweeps with one longer sweep; the
asymptotic LF stage saving is about29 percent, before snapshot/reduction costs.
Rejects pay discarded stages, the restored old post, and a fresh mesh timestep.
The tiny regression timings are diagnostic only, not performance measurements.

Remaining checks and limits
---------------------------
The HIP counterpart is compiled and run_merge_hip.sh is ready, but application
execution is paused by the parent while uncontended baseline timing completes.
Its plan covers default-off/output bytes, smooth on/off comparison, and actual
CFL rejection on1 and4 GPU ranks. A uniform multiblock test proves MPI agreement;
it does not establish AMR merge semantics (AMR is ineligible). AMR fallback has
been inspected but not executed in this Task2-specific suite. Corrupted-state
admissibility rollback is reviewed but only genuine CFL rollback is executed.
Production pytest packaging, integrated Task0/Task1 compatibility, and useful
representative GPU timing remain required before recommending production adoption.
